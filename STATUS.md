# epok — status log

Append-only. One line per finished item, newest at the bottom. Never rewrite an
existing line; never delete one.

**Line formats**

```
<date> <time> · <window> · <item> done · <what was run and what it printed>
<date> <time> · <window> · NEEDS: <file> — <what you need, and why>
<date> <time> · <window> · CONTRACT: <interface> — <proposed change and reason>
<date> <time> · <window> · ACK: <the CONTRACT line being acknowledged>
<date> <time> · <window> · BLOCKED: <what on>
```

A `NEEDS:` line is how you get a change made in a file you don't own. Post it
and move to your next item — never edit someone else's file, and never wait on
it if there is other work.

A `CONTRACT:` line stops that thread of work until the owning window posts an
`ACK:`. Everything else in your queue continues.

Leases and window assignments are in `PLAN-epok.md § Parallel windows`.
